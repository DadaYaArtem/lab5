# Графовый редактор - Лабораторная работа №5

Программа для создания и редактирования графов с поддержкой различных операций и алгоритмов.

## Возможности

### Общие функции (обязательные требования):
- ✅ MDI интерфейс (работа с несколькими графами одновременно)
- ✅ Именование и переименование графов
- ✅ Сохранение и загрузка графов во внутреннем формате
- ✅ Создание, удаление, именование, переименование узлов
- ✅ Перемещение узлов мышью
- ✅ Создание ориентированных и неориентированных рёбер
- ✅ Удаление рёбер и узлов (с автоматическим удалением связанных рёбер)
- ✅ Настройка цвета узлов и рёбер
- ✅ Информация о графе: количество вершин, рёбер, степени вершин

### Специальные функции:
- ✅ Проверка является ли граф деревом
- ✅ Приведение графа к обычному дереву (остовное дерево)
- ✅ Приведение графа к бинарному дереву
- ✅ Поиск гамильтоновых циклов
- ✅ Вычисление диаметра графа
- ✅ Вычисление радиуса графа
- ✅ Нахождение центра графа
- ✅ Декартово произведение двух графов
- ✅ Тензорное произведение двух графов

## Запуск программы

### Вариант 1: Запуск JAR (самый простой)
```bash
# Если JAR уже собран
java -jar target/graph-editor.jar

# Если нужно пересобрать
./run.sh
```

### Вариант 2: Прямая компиляция
```bash
# Компиляция
mkdir -p target/classes
find src -name "*.java" | xargs javac -d target/classes

# Создание JAR
cd target/classes && jar cfe ../graph-editor.jar com.grapheditor.Main . && cd ../..

# Запуск
java -jar target/graph-editor.jar
# или
java -cp target/classes com.grapheditor.Main
```

### Вариант 3: Через Maven (требуется интернет)
```bash
mvn clean package
java -jar target/graph-editor-1.0-SNAPSHOT.jar
```

### Вариант 4: Консольная версия
```bash
# Компиляция
mkdir -p target/classes
find src/main/java -name "*.java" | xargs javac -d target/classes

# Запуск консольной версии
java -cp target/classes com.grapheditor.ConsoleMain
```

## Использование

### Создание графа
1. `Файл → Новый граф` - создать новый граф
2. Используйте панель инструментов в окне графа:
   - **Выбор** - выбор и перемещение узлов
   - **+ Узел** - добавление узлов (клик на пустом месте)
   - **+ Ребро** - добавление неориентированного ребра (клик на два узла)
   - **+ Дуга** - добавление ориентированного ребра (клик на два узла)
   - **Удалить** - удаление узлов или рёбер (клик на элемент)

### Редактирование
- **Переименовать** - переименование узла
- **Цвет узла** - изменение цвета узла
- **Цвет ребра** - изменение цвета всех рёбер
- `Граф → Переименовать граф` - изменение имени графа

### Сохранение и загрузка
- `Граф → Сохранить` - сохранение графа в файл
- `Файл → Открыть` - загрузка графа из файла

### Информация и алгоритмы
- `Граф → Информация` - просмотр информации о графе
- `Алгоритмы → Проверить дерево` - проверка является ли граф деревом
- `Алгоритмы → Гамильтонов цикл` - поиск гамильтонова цикла
- `Алгоритмы → Диаметр, радиус, центр` - вычисление метрик графа

### Операции над графами
- `Операции → Декартово произведение` - создание декартова произведения двух графов
- `Операции → Тензорное произведение` - создание тензорного произведения двух графов
- `Операции → Преобразовать в дерево` - построение остовного дерева
- `Операции → Преобразовать в бинарное дерево` - построение бинарного дерева

### Управление окнами
- `Окна → Каскадом` - расположение окон каскадом
- `Окна → Плиткой` - расположение окон плиткой

## Примеры использования

### Создание простого графа
1. Создайте новый граф
2. Добавьте несколько узлов кликами мыши
3. Выберите режим "+ Ребро"
4. Кликните на два узла для создания ребра
5. Повторите для других рёбер

### Проверка на дерево
1. Создайте граф
2. Меню `Алгоритмы → Проверить дерево`
3. Программа покажет является ли граф деревом

### Создание произведения графов
1. Создайте два графа
2. Меню `Операции → Декартово произведение`
3. Выберите два графа из списка
4. Программа создаст новый граф - результат произведения
